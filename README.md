# Grokking Neural Nets (Go)

Projekt przeznaczony do nauki sieci neuronowych w języku Go.

## Podręcznik
Głównym materiałem szkoleniowym wykorzystywanym w tym projekcie jest **Grokking Deep Learning** autorstwa Andrew W. Traska.

## O projekcie
Celem jest implementacja algorytmów sieci neuronowych od podstaw w języku Go, podążając za przykładami z powyższego podręcznika.

## Wymagania
- Go 1.25 lub nowszy
